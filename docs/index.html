Obsidian plugin · Markdown and plain text · v0.1.0

A quote should remember
when its source changed.

Capture a passage. Keep its exact text and source hashes. Detect edits, survive tracked renames, and refuse to guess when two copies could be the original.

This is a public-API extension. It does not claim to recover Obsidian internals with REA. A matching hash means unchanged saved text; it does not establish that a scientific claim is true.

Conservative by design
Verified
Both saved source text and the captured passage still match. The stable anchor ID is independent of the current path.
Stale
Any source-text edit invalidates verification. Revalidate only after reviewing a unique, exact quotation and its captured context.
Ambiguous
Multiple source copies or identical quote/context matches remain. The plugin offers an explicit source-choice action instead of picking one.
Missing / unavailable
A deleted source, unreadable file, partial scan or unsupported format stays unresolved. Whitespace and Unicode normalization never silently repair an anchor.


Install in a test vault first
Download plugin and demo-vault ZIPs · Source repository
  1. Download the plugin ZIP from this repository’s GitHub Release.
  2. Extract its evidence-anchor folder into your vault’s .obsidian/plugins/ directory.
  3. Reload Obsidian, enable community plugins for that test vault, then enable Evidence Anchor.
  4. Select a passage in a saved Markdown note. Run Evidence Anchor: Capture selection as evidence from the command palette.
  5. Use the right-side panel to check status, open a source, copy a citation or explicitly revalidate. The status bar opens the panel.
A separate demo-vault ZIP contains synthetic notes and a preloaded anchor. Review the installation and behavior guide before using an existing vault.
Scope: .md and .txt text only. The capture command is available in an editor surface; plain-text checking is supported when the host exposes that source. PDFs, scanned pages, images, remote URLs and PDF coordinates are deliberately unsupported.
Limits: 2,000 anchors; 8,000 UTF-16 code units per quote; 2 MiB per file; 5,000 text files / 32 MiB per check. The ledger retains its original capture and the latest 99 revisions. Quotes and metadata stay in the plugin’s local vault data; Obsidian Sync or other vault synchronization can still copy them.

What was actually verified
Automated: core fixtures for stale sources, tracked and untracked renames, duplicate sources, quote/context ambiguity, Unicode, whitespace, source disappearance, stale-check races and persisted-data validation. The compiled plugin is also loaded with explicit Obsidian API mocks and a real DOM implementation to test commands, panel rendering, event handling, refusal paths and text-safe quote rendering.
Limit: API mocks and browser demonstrations do not establish integration in a real Obsidian desktop host. No installed Obsidian application or private vault was read. A portable host was not launched because its outside-directory writes could not be verified under the task’s strict workspace-only constraint. The release is an installable candidate pending real-host validation.
See machine-readable verification, pinned sources and attribution, and the repository’s tests.
