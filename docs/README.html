Install Evidence Anchor and review a saved quote.

Save a passage from a source note and keep a record of the text it came from. If that source changes later, the plugin marks the saved evidence for review instead of silently treating it as unchanged.

Install

Unzip the plugin release into a test vault's .obsidian/plugins/ directory. Enable Evidence Anchor under Community plugins after reloading Obsidian. The ZIP includes compiled JavaScript, manifest and styles; npm is unnecessary for installation.

Capture and inspect

  1. Save the source note. Select a nonempty passage.
  2. Run Evidence Anchor: Capture selection as evidence.
  3. The right-side panel shows status, quote, tracked path, hashes and the revision ledger.
  4. After edits, choose Check all. Any source text change makes the anchor stale even if its quotation is unchanged.
  5. Review the source. Revalidate is available only when one exact quotation and captured context remain. Quote/context changes require recapture.

Rename, duplicates and deletion

Renames observed through Obsidian's vault event preserve the anchor ID. If a stored path disappears and one identical file is found in a complete scan, explicit relocation confirmation is required. Multiple copies remain ambiguous. Focus your intended source and use “Choose active note as source”; the confirmation records your choice, rather than pretending file ancestry was proven.

Data and scope

The plugin writes only its own data.json. It never edits source notes and has no network calls. Quotes can still be copied by your vault-sync software. Hashes cover decoded text encoded as UTF-8, not original disk encodings, authorship or scientific validity.

Only .md/.txt sources are supported; capture requires a host editor surface. PDF, OCR, images and remote-page evidence are unsupported. A read error, scan budget or unsupported extension produces an unavailable state. Do not delete corrupted plugin metadata to “fix” an error without preserving it first; the plugin intentionally stops writes.

Verification limits

Automated evidence-core tests and compiled-plugin API/DOM mocks pass as recorded in verification.json. A real Obsidian host has not been verified. Minimum version1.5.0 is declared, not host-tested. Treat this as an installable release candidate.
